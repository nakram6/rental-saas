# Rental SaaS – Project Overview

A multi-tenant SaaS platform built with:
- Laravel (API backend)
- React + Vite (SPA frontend)
- Laravel Sanctum authentication
- Universal rental logic (items, bookings, customers, availability)

## Goals
- Allow any rental business (decor, tools, cameras, party supplies) to manage inventory and bookings.
- Public storefront with real-time availability.
- Admin dashboard for tenants.
- Multi-tenant architecture (per business).
